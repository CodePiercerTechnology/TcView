# Contributing to TcView

## Development Setup

1. Install Node.js 20+.
2. Install dependencies with 
pm install.
3. Build with 
pm run compile.
4. Run tests with 
pm test.

## Pull Requests

- Keep PRs focused and small.
- Add or update tests when behavior changes.
- Update docs when commands, config, or UX changes.
- Ensure 
pm run compile and 
pm test pass before requesting review.

## Commit Guidance

Use clear commit messages that explain the change and its impact.
